# Inventory Insights — Flows

> [Inventory (Notion)](https://www.notion.so/34f64094bde6802697c3e75140af7797)

## 1. Daily Overview (Notion #1)

Morning → Overview this week → 6 tiles + trend + alerts → tap alert → drill to tab/module.

## 2. Variance investigation (Notion #2)

Tap variance tile → Variance tab → top ingredients → ingredient detail history.

## 3. Waste deep dive (Notion #3)

Waste tab → by reason / location / shift filters.

## 4. Supplier price scan (Notion #4)

Suppliers tab → sort price change YTD → expand supplier products.

## 5. Menu engineering (Notion #5)

Recipes tab → quadrant view → tap recipe → margin drill-in.`

## 6. Period comparison (Notion #8)

Enable compare → deltas on all tiles.

## 7. Multi-venue rollup (Notion #9)

All venues → per-venue mini-tiles → drill Brunswick.

## 8. Agent card (Notion #12)

Proactive waste anomaly → dig deeper in Agent.
