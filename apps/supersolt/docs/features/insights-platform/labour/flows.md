# Labour Insights — Flows

> [Labour (Notion)](https://www.notion.so/34f64094bde68049a7b8e8c87db97f1f)

## 1. Weekly review (Notion #1)

Owner opens Labour → Overview → last week KPIs + top 3 flags → tap tile → Wage Cost tab.

## 2. Wage % spike (Notion #2)

Tap wage % tile → Wage Cost tab pre-filtered → daily chart + per-position + per-employee tables.

## 3. Scheduled vs actual (Notion #4)

Hours & Schedule tab → variance chart → per-employee attendance patterns.

## 4. Compliance flag (Notion #5)

Overview flag → Compliance tab → cert list → link to People.

## 5. Demo transition (Notion #10)

No payroll → seeded data + banner → first payroll → banner removed, real aggregates.

## 6. Agent insight (Notion #11)

Morning brief link → Labour Wage Cost with context query params.

## 7. Capacity gap (Notion #12)

Forecast + Roster live → Overview flag → Hours & Schedule overlay → link draft shifts to Roster.

## 8. Error / alt

| Case | UI |
|------|-----|
| Staff access | 403 |
| Filter empty | Widen range message |
| Compliance clear | Positive empty state |

## 9. Acceptance

Six tabs match Notion order; Demo badges on deferred sections until prerequisites land.
